## Olá! Eu sou o Alexandre 👋

Criei o **[Simples Obra](https://simples-obra.lovable.app)**, uma calculadora grátis de materiais de construção.
Você informa as medidas e ela gera a lista de materiais: tijolos, cimento, areia, brita, ferro, telhas, piso e tinta.
